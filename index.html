About Me

Hi there! I'm a full-stack developer who genuinely loves building things for the web. My passion lies in crafting both intuitive, beautiful user interfaces and the powerful, efficient backend systems that drive them.

I specialize in creating responsive, high-performing web applications. On the frontend, I'm all about modern JavaScript frameworks. For the backend, I work with Node.js and robust databases like PostgreSQL. Plus, I handle the entire deployment process, getting applications up and running smoothly on cloud platforms like AWS.

I really enjoy collaborating with teams and am always eager to dive into new technologies and best practices to deliver top-notch code. When I'm not coding, you can usually find me exploring various tech articles, contributing to open-source projects, or simply enjoying a good book.
